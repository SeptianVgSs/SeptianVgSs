## 🔭 What I'm building

- **[DeliveryEscrow](https://github.com/SeptianVgSs/delivery-escrow-genlayer)** — a GenLayer Intelligent Contract for delivery disputes. A buyer funds an order in GEN with an approved carrier; funds release on buyer confirmation, refund on seller cancellation, or are decided by an LLM judge that reads the delivery record — only after the record is verified to contain the order's tracking number. Written in Python and tested in GenLayer Studio.
